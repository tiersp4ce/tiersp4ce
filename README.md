### Principais Projetos

* **PyNotas_Analytics:** Ferramenta para extração e processamento de dados em arquivos XML de Notas Fiscais Eletrônicas, utilizando a biblioteca `xml.etree.ElementTree`.
* **Company_Register:** Aplicação em Python focada no gerenciamento de cadastros de estabelecimentos comerciais via interface de terminal.
* **Mini-ETL de Vendas:** Script de automação para processar dados brutos imobiliários, realizando cálculos lógicos de comissão e gerando relatórios de desempenho.
* **API de Gestão de Biblioteca (🚧 Em Desenvolvimento):** Construção de uma API robusta para controle de acervo, empréstimos e persistência de dados utilizando conceitos de POO.
